# Memoria Contextual MCP AQL Protección

## Gestión de Facturación B2B
- **Peculiaridad de Facturación**: AQL tiene la opción de facturas en tienda online desactivada (`PS_INVOICE = 0`). Las facturas contables las tramita su dpto. de administración vía ERP.
- **Seguimiento B2B**: En el portal se registran los pedidos de compra B2B con estado `Facturado`, `Enviado` o `Pendiente`.
